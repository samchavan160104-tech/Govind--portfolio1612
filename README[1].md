# Govind Chavan — 3D-inspired portfolio preview
Built with plain HTML, CSS and JavaScript. No paid tools or frameworks required.

## Test locally
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Double-click `index.html` to open it in your browser, or use VS Code Live Server.
4. Test desktop and mobile layout.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
- Replace the LinkedIn placeholder with your real profile URL.
- Keep project descriptions accurate and add verified demo/repository links when ready.
- Google Fonts needs internet; fallback system fonts work offline.

## Safe publishing plan
Test this preview first. Do not overwrite the live GitHub `main` branch until you have checked the new version.
